# Scope and attribution

This repository is an isolated publication artifact for **Verify Before You Build: Executable Dependency Gates for Agent-Generated Science**, by Mariia Baidachna and Alina Nesen. Its Git history begins with one publication commit; it does not import the development history of the broader research workspace.

The original Python supplement and historical Efferents excerpts retain their Apache-2.0 LICENSE and NOTICE files. No new blanket license is asserted for the manuscript, Minecraft adapter, or third-party artwork by this export. Minecraft names and item artwork belong to Mojang/Microsoft. Figure 2 uses a small set of item illustrations in a research diagram; raw texture files, the game jar, model weights and recordings are not redistributed. Its generator reads assets from an independently installed game.

`provenance/export-manifest.json` records original and published evidence hashes. Published UTF-8 evidence copies replace the author's absolute home prefix with `$AUTHOR_HOME`; these are declared redactions, not byte-identical originals. This does not change measurements, timestamps, model actions, recipe steps or receipt identities. Frozen executable source snapshots are unmodified; recorded source hashes refer to those historical files. The new `portable/` wrappers provide dependency-path portability and are not the source versions used to generate the reported episodes.

The historical framework excerpts are inspection material, not a complete Efferents installation. The original evaluator output did not record its framework commit. The standalone supplement uses a predetermined five-value fixture to test verdict logic; it does not train a classifier.
